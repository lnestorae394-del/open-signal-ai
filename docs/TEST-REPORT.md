## Что покрыто тестами
- Онбординг: новый пользователь на шаге 1; сигналы и академия закрыты до завершения; после перезапуска и на другом устройстве открывается сохранённый шаг; шаг нельзя пропустить.
- Trader ID: только формат не принимается (`REGISTRATION_NOT_CONFIRMED`); чужая регистрация (`CLICK_MISMATCH`); регистрация без `click_id` не привязывается никому; занятый Trader ID; пользователь не может сменить привязанный ID.
- FTD / redeposit: подтверждение только из postback ≥ $10; меньше $10 → «Ошибка»; без суммы → «Проверяется»; повтор FTD с другой суммой не заменяет сумму; повторные депозиты без ID события засчитываются все (одинаковые в пределах 10 минут помечаются «Возможный повтор» для администратора); депозит по чужому `click_id` не засчитывается.
- Повторная доставка: 5 последовательных и 10 одновременных доставок → одно событие.
- Изоляция botId: один глобальный postback, события уходят боту владельца `click_id`; 100 ботов на одном сервере; сессия и initData одного бота не работают в другом.
- Безопасность postback: неверный секрет 401 (с записью в журнал), неизвестный источник 404, неверные данные 400, HMAC-подпись.
- Сигналы: общие настройки, пометка «учебный», отсчёт по серверному времени, пауза и дневной лимит.
- Академия: общий каталог, стартовый курс, прогресс по пользователю; разбор текста урока и ссылок на видео.

## Сценарий в браузере (мобильный размер)
Шаг 1 → «Зарегистрироваться» (ссылка с `click_id` и `bot_id`) → неверный Trader ID → ошибка и «Попробовать ещё раз» → возврат к шагу 1 → postback регистрации → шаг 3 «Ожидается» → postback FTD $50 → сигналы → выбор пары → подготовка → SELL → «Открыл сделку» → отсчёт → завершение → академия → урок → профиль → перезапуск без онбординга → вне Telegram только ссылка на бота → английский интерфейс. В консоли браузера только ожидаемые ответы 401 (до входа) и 409 (неподтверждённый Trader ID).

## Что НЕ проверено
- **Реальные редиректы Pocket Partners**: сохраняется ли `click_id` после всех переходов. Проверяется одной тестовой регистрацией после деплоя.
- **Реальные макросы Pocket Partners** `{click_id}`, `{trader_id}`, `{sumdep}` и название параметра трекинговой ссылки — взяты из открытых материалов, нужно сверить с кабинетом.
- **Настоящий Telegram** (подпись initData реальным ботом, открытие внешней ссылки из Mini App на iOS/Android) — проверено только на тестовом двойнике Telegram.
- **Настоящий Firestore** — проверено на тестовом двойнике REST API; создание новых индексов в вашем проекте произойдёт при первом запуске.
- **`npm install` из интернета и `package-lock.json`** — в среде проверки нет доступа к npm; lock-файл создаётся у вас командой `npm install`.
- **Официальные типы React** — проверка TypeScript Mini App и админки шла с упрощёнными типами React; на вашем компьютере `npm run typecheck` проверит с официальными.
