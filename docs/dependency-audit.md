# Зависимости и аудит

## Что попадает на сервер
Рабочие зависимости: `zod`, `react`, `react-dom` (React собирается в статические файлы на этапе сборки и на сервере не исполняется). Сервер использует только встроенные модули Node.js: `node:http`, `node:crypto`, `fetch`. Fastify, Vite и `firebase-admin` больше не используются: это убрало основную часть транзитивных зависимостей, из которых приходили предупреждения `npm audit`.

## Инструменты сборки (только во время сборки)
`typescript`, `esbuild`, `tailwindcss`, `@types/*`.

## Правила
- `npm audit fix --force` не используется.
- `npm run audit:prod` — только то, что попадает на сервер. Исправляется обязательно.
- Предупреждения в инструментах сборки исправляются обновлением в пределах мажорной версии.
