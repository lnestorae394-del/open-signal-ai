# Запуск с нуля на своём компьютере

Пошаговая инструкция. Команды копируйте целиком. Никаких ключей никуда отправлять не нужно: всё вводится только у вас на компьютере.

## Шаг 1. Установить Node.js (нужна версия 22.18.0 или новее)
Проект запускает TypeScript напрямую средствами Node.js, а это включено по умолчанию только начиная с **22.18.0**. На более старой версии `npm install` остановится с ошибкой `EBADENGINE`, а проверки выведут понятное сообщение.

**Mac:**
1. Откройте https://nodejs.org/en/download.
2. Выберите версию **22 (LTS)**, платформу **macOS** и тип **Installer (.pkg)**, затем скачайте файл.
3. Откройте скачанный `.pkg` и нажимайте «Продолжить» → «Установить» (Mac попросит пароль от компьютера).
4. Закройте Терминал полностью (⌘ + Q) и откройте снова.

**Windows:** на той же странице выберите **Windows Installer (.msi)** и установите, нажимая «Далее».
3. Откройте **Терминал**: на Mac — Spotlight (⌘ + Пробел), введите «Терминал»; на Windows — меню Пуск, введите «PowerShell».
4. Проверьте версию:
   ```bash
   node -v
   ```
   Должно быть `v22.18.0` или выше (например, `v22.20.0`). Если версия старше, повторите установку.

## Шаг 2. Распаковать проект
1. Распакуйте архив `open-signal-ai.zip`, например в папку «Документы».
2. Перейдите в папку проекта (путь замените на свой):
   ```bash
   cd ~/Documents/open-signal-ai
   ```

## Шаг 3. Установить зависимости (бесплатно)
```bash
npm install
```
Займёт 1–3 минуты. Предупреждения (`WARN`) — это нормально.

## Шаг 4. Создать секреты (только у вас)
```bash
cp .env.example apps/api/.env
npm run gen:key -w @open-signal/api
```
Команда выведет три строки: `ENCRYPTION_KEY=…`, `ENCRYPTION_KEY_ID=k1`, `SESSION_SECRET=…`.
1. Откройте файл `apps/api/.env` в любом текстовом редакторе.
2. Замените пустые строки `ENCRYPTION_KEY=`, `ENCRYPTION_KEY_ID=k1` и `SESSION_SECRET=` на три строки из вывода команды.
3. Сохраните файл.

> Эти значения никому не отправляйте, в том числе в чат. Если ENCRYPTION_KEY потерян, сохранённые токены ботов придётся вводить заново.

## Шаг 5. Проверить проект
```bash
npm test
```
В конце должно быть написано `fail 0`.

## Шаг 6. Создать локального тестового бота
```bash
npm run seed:dev
```
Команда покажет `Dev bot created: dev…` и ссылку на Mini App. Скопируйте ссылку.

## Шаг 7. Запустить (три окна терминала)
Окно 1 — API:
```bash
npm run dev:api
```
Окно 2 — Mini App:
```bash
npm run dev:miniapp
```
Окно 3 — админка:
```bash
npm run dev:admin
```
Откройте в браузере:
- Mini App: ссылку из шага 6 (вида `http://localhost:5173/?bot=dev…`);
- админку: http://localhost:5174.

В обычном браузере Mini App работает в режиме предпросмотра: вход возможен только внутри Telegram, это подключается на этапе 3.

## Остановить
В каждом окне нажмите `Ctrl + C`.
