# Обновление уже развёрнутого сервиса на Render

Переменные окружения и проект Firebase не меняются: новые функции используют те же `ENCRYPTION_KEY`, `SESSION_SECRET`, `ADMIN_SETUP_TOKEN` и `FIREBASE_SERVICE_ACCOUNT`. Данные в Firestore сохраняются: старые настройки ботов автоматически дополняются новыми полями при чтении (партнёрская ссылка из старого поля переносится в новый раздел).

## 1. Заменить файлы в папке проекта

1. Распакуйте новый архив во временную папку.
2. Скопируйте всё его содержимое в вашу папку `open-signal-ai` с заменой файлов. Папки `.git` и файл `.env` (если есть) не трогайте.
3. Удалите из вашей папки файлы, которых больше нет в архиве. Проще всего так (выполнять в папке проекта на Mac):

```bash
cd ~/open-signal-ai
git status
```

Команда покажет изменённые и удалённые файлы. Если в списке есть `.env` или `*firebase-adminsdk*.json` — остановитесь: этих файлов не должно быть в git.

## 2. Проверить у себя (рекомендуется)

```bash
npm install
npm run check
```

`check` запускает строгую проверку TypeScript, сборку и все тесты. В конце должно быть `# fail 0`.

## 3. Отправить в GitHub

```bash
git add -A
git commit -m "Onboarding, partner links, Forex/OTC simulation, admin sections"
git push
```

Render сам начнёт новый деплой (около 3 минут). Если сборка или проверка `/health` не пройдёт, Render оставит работать прежнюю версию.

## 4. Проверить после деплоя

1. Откройте `https://<ваш-адрес>/health` — должно быть `"status":"ok"` и `"persistentStorage":true`.
2. Админка → **Обзор** → блок «Индексы базы данных». Новый индекс создаётся автоматически при запуске, обычно за несколько минут.
3. Админка → **Боты** → ваш бот → вкладка **Партнёрская ссылка**: вставьте ссылку с `{click_id}`, нажмите **Сохранить**, затем **Проверить ссылку**.
4. Вкладка **Telegram** → **Синхронизировать с Telegram**. Все шаги должны быть «Подтверждено», статус webhook — «Работает».
5. Вкладка **Настройки** бота → модуль «Привязка аккаунта» включите, если нужен онбординг из трёх шагов. Без него Mini App открывается сразу на основном экране.
6. Откройте бота в Telegram → `/start` → кнопка приложения.
